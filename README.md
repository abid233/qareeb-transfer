# قريب

> نقل ملفات مباشر وآمن بين جهازين عبر QR وWebRTC — بلا حسابات وبلا تخزين للملفات.

## كيف يعمل؟

1. ينشئ الجهاز المُرسل جلسة مؤقتة ويعرض QR.
2. يمسح الجهاز المُستقبل الرمز لربط المتصفحين.
3. ينقل WebRTC الملف مباشرة بين الجهازين عبر قناة بيانات مشفّرة.
4. لا يخزن خادم «قريب» الملفات؛ دوره يقتصر على تمرير رسائل الربط المؤقتة.

## المزايا

- واجهة عربية RTL متجاوبة.
- ربط سريع عبر QR أو رمز جلسة.
- نقل صور وملفات مباشرة بين جهازين.
- نسبة تقدم للإرسال والاستقبال.
- سحب وإفلات للملفات.
- لا حسابات ولا قاعدة بيانات.
- خادم إشارات WebSocket مدمج بلا حزم خارجية.

## التشغيل

يتطلب Node.js 20 أو أحدث.

```bash
npm start
```

ثم افتح:

```text
http://localhost:3000
```

> لتجربة جهازين مختلفين، شغّل الخادم على عنوان عام HTTPS أو على شبكة محلية يمكن للجهاز الثاني الوصول إليها. WebRTC يستخدم خادم STUN عام لاكتشاف الاتصال ولا يمرّر الملف عبره.

## ملاحظة تقنية مهمة

قد تمنع بعض الشبكات الصارمة الاتصال المباشر بين الجهازين. لذلك ستحتاج النسخة الإنتاجية إلى خادم TURN موثوق كحل احتياطي؛ وعند استخدامه قد تمر البيانات المشفرة عبره دون تخزينها.

## التقنية

- Node.js HTTP + WebSocket signaling بدون اعتماديات.
- WebRTC DataChannel لنقل الملفات.
- HTML/CSS/JavaScript بواجهة عربية.
- QR عبر مكتبة CDN.
